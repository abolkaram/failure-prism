# README Design Contract

## readmeArchetype
failure analysis incident packet

## readmeNarrativeVoice
terse safety engineer annotating a destructive test

## readmeSectionPattern
containment notice, specimen card, pressure cycle, invariant locks, operator sequence, fracture log

## readmeMotif
marked pressure-vessel inspection packet

## requiredFactsPlacement
Identity and links sit on the specimen card. State, methods, consensus, and guards live in the pressure cycle and invariant locks. Setup and tests are an operator sequence. Limits close the fracture log.

## bannedReadmePatterns
No radio transcript, continuity slate, generic feature list, marketing introduction, standard architecture headings, or installation-first opening.

## proofOfDifference
The document begins with a containment warning and reads as a destructive-test packet, unlike the recent editing-room log and radio service transcript.
